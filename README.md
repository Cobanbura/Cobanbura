## 🧭 About Me

I'm a software engineer who blends **creative design with solid engineering**.
I started out in **Naval Architecture & Ocean Engineering**, built **underwater robots** for 3+ years, then moved into software: ~5 years as a **Unity developer** shipping mobile games, followed by a role as a **QA Automation Specialist** building test frameworks.

Today I combine both worlds: crafting engaging interactive experiences, and making sure they're rock solid.

> *Somehow I ended up steering game engines instead of ships.* ⚓➡️🎮
